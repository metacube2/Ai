# Berndeutsch fuer das Trafag Dashboard: Stil und Glossar

Ziel: lesbares, natuerliches Bärndütsch fuer eine Firmen-Webapp (Finance, HR, Einkauf, SAP). Freundlich,
knapp, nicht folkloristisch. Gleiche Begriffe immer gleich schreiben.

Schreibweise (verbindlich):
- ist -> isch, nicht -> nid, und -> u, ein/eine -> e/es, auch -> o, schon -> scho, noch -> no,
  kein -> ke/kes, alle -> aui, viel -> vüu, wenn -> we, weil -> wüu, wird -> wird, werden -> wärde,
  haben/hat -> ha/het, sind -> si, gibt -> git, Sie (Anrede) -> Dir / Öich (Höflichkeitsform Bern), du nie.
- Verben im Infinitiv: lade, speichere -> spichere, anzeigen -> aazeige, aktualisieren -> aktualisiere,
  prüfen -> prüefe, auswählen -> uswähle, herunterladen -> abelade, hochladen -> uelade, schliessen -> zuemache,
  öffnen -> ufmache, löschen -> lösche, suchen -> sueche, starten -> starte, anmelden -> aamäude.
- Lädt... -> Ladet …, Wird geladen -> Wird glade, Fehler -> Fähler, Keine Daten -> Kener Date,
  Bitte -> Bitte, Datum -> Datum, Jahr -> Jahr, Monat -> Monet, Woche -> Wuche, heute -> hüt,
  gestern -> geschter, Zeitraum -> Zytruum, Zeit -> Zyt, Stunden -> Stunde, Tage -> Täg,
  Mitarbeitende -> Mitarbeitendi, Lieferant -> Lieferant, Umsatz -> Umsatz, Kosten -> Choschte,
  Menge -> Mängi, Wert -> Wärt, offen -> offe, erledigt -> erlediget, neu -> nöi, alt -> aut,
  gross -> gross, klein -> chlii, oben -> obe, unten -> unde, links -> links, rechts -> rächts.
- Fachbegriffe, Abkuerzungen und Eigennamen UNVERAENDERT lassen: SAP, OData, EKKO, EKPO, MARA, CHF, EUR,
  FTE, KPI, HR, Rexx, Trafag, Cockpit, Dashboard, Export, Import, Finance, Railway, ISS-..., PM-..., Feldnamen,
  Dateinamen, Tabellennamen, Codes in Backticks oder GROSSBUCHSTABEN, Zahlen, Prozentzeichen, Einheiten.

Technische Regeln (zwingend):
- Platzhalter wie {0}, {1}, {Seconds:N1}, {Name}, %s, {{...}} exakt uebernehmen, nicht uebersetzen.
- HTML-Tags, Markdown, Zeilenumbrueche (\n), fuehrende/abschliessende Leerzeichen und Satzzeichen
  (Doppelpunkt, Pfeile, Klammern, …) erhalten.
- Sehr kurze Begriffe (Spaltenkoepfe) kurz lassen.
- Ist ein Text bereits Englisch oder ein reiner Code, ihn unveraendert uebernehmen.
